### 🛠 Things I've built

**Gauravide** · [gauravide.vercel.app](https://gauravide.vercel.app)
Snap a receipt, tap who had what, and the itemized split lands in Splitwise. Designed and built end to end, free to use with a regular Splitwise account.

**AI Job Application Agent**
A local multi agent system built with Claude Code and Playwright MCP. Six agents handle discovery, matching, tailoring, applying and tracking, with a human confirmation step before anything gets submitted and a hard rule against fabricating experience.

**Figma to React MCP Pipeline**
A Claude Code workflow that turns design system components in Figma into production React code, closing the gap between design handoff and what actually ships.

**Allie / Skaimart**
An AI shopping assistant that beat Amazon Rufus in 18 of 20 head to head A/B comparisons.
