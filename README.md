### 🛠 Things I've built

**Gauravide** · [live](https://gauravide.vercel.app) · [design record](https://github.com/gauravbasantani/gauravide-design)
Snap a receipt, tap who had what, and the itemized split lands in Splitwise, with tax going to whoever bought the taxed item. I designed it and directed Claude Code to write the implementation. 15 real splits worth $1,337.26 across 90 items in its first 30 days. The source is private because it holds OAuth credentials, so I published the architecture, the decisions, and a log of nine failures that never threw an error.

**Job Agent** · [github.com/gauravbasantani/job-agent](https://github.com/gauravbasantani/job-agent)
An open source, file based system for running a job search with an AI coding agent. Scores postings across seven dimensions, four of which a script **refuses to let tailoring improve**, because rewriting a resume does not give you more years of experience. Never auto submits. No dependencies, Python and Node standard library only. Fork it and make it yours.

**LIVE** · [live.lei-tech.org](https://live.lei-tech.org)
An AI video workspace at ASU where faculty make short teaching videos by talking to an assistant instead of learning editing software. Built by three designers; I wrote the instructions and skills the AI follows, the eight step conversation with two human approval checkpoints, and we tested it by running eight fresh AI agents as new users.

**Allie / Skaimart**
An AI shopping assistant that 18 of 20 testers preferred over Amazon Rufus.
